# 신양愛소리

추자도 신양2리 사운드스케이프 힐링 맵. 추자도의 실제 지도와 관광지, 여객선 결항 확률을 보여 주는 발표용 시연 앱입니다.

## 폴더
| 폴더 | 내용 |
|---|---|
| `data/live.json` | 앱이 받아 가는 그날 아침 자료(운항 편성, 추자도 부이 파고·풍속, 해상예보). 매일 아침 바뀝니다. |
| `결항앱/` | 앱 화면과 확률 계산의 소스. `refresh.py`가 자료를 받아 `chuja-guide.html`을 만듭니다. |
| `안드로이드앱/신양애소리.apk` | 안드로이드 설치 파일 |
| `안드로이드앱/빌드소스/` | APK를 만드는 소스와 방법(README 참고) |
| `publish_live.py` | `결항앱/data.json`에서 그날 자료만 꺼내 `data/live.json`으로 쓰는 스크립트 |

## 앱이 매일 바뀌는 방식
앱을 열면 `data/live.json`을 받아 결항 확률을 다시 계산합니다. 인터넷이 안 되면 마지막으로 받은 자료를 날짜와 함께 보여 줍니다.

## 자료 출처
한국해양교통안전공단 「항로별 여객선 운항상황 현황」·「운항 스케줄 정보」·해양기상 모니터링 시스템, 기상청 API허브 해상 관측자료와 해상예보, 지도 © OpenStreetMap contributors.
